# Generated experiment outputs

The notebook writes to `results/transformers/` under the project root,
or `/kaggle/working/results/transformers/` on Kaggle. These generated files
are ignored by Git. Row-level predictions retain post IDs and annotations.

See [the results guide](../docs/RESULTS_GUIDE.md) to interpret each file.
Copy reviewed aggregate figures/tables into `reports/` for sharing.
